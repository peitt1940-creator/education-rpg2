# 校園真相調查局

## 玩法
媒體識讀主題的俯視地圖 RPG。玩家是校刊編輯員，要查證校園裡流傳的消息，寫出有根據的報導。

1. 開場接下主編的委託，進入地圖。
2. 在圖書館、四年級教室、校刊社、校園走廊、資料室五個場景走動，靠近人物或文件就能對話、取得資料。
3. 回到校刊社編輯桌，依序選擇立場、標題、內文，並勾選要引用的證據。
4. 送審後會收到回饋；判斷正確就結案，進入下一案。

共 5 案：閱讀週的驚人數字、消失的午餐、不存在的校長公告、冠軍班級爭議、校園神祕黑影，分別練習統計解讀、照片脈絡、截圖真偽、比較基準、證據交叉核對。

操作：電腦用方向鍵或 WASD 移動；手機、平板用畫面上的方向鍵與調查鍵。
